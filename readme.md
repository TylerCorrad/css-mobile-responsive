# CSS personalizado para osTicket
El código encontrado dentro de este proyecto será usado para la implementación de una interfaz responsive dentro de la plataforma osTicket.
## Compatibilidad
Este código fue desarrollado en base a la versión 1.18.2. Si deasea implementarlo en otras versiones de osTicket, hagalo con precaución.
## Implementación 
Para implementar estas reglas de css debe inyectar el código correspondiente dentro de la etiqueta *head* de los archivos header.inc.php de las carpetas /include/client/ e /include/staff/. Ya sea de manera directa, por medio de hooks o algún otro método.
